Contact

Contact ChipRatio

Reach the ChipRatio project through the channels below for bugs, feature ideas, licensing questions, or anything that should not live in a public thread.

Private questions

For questions about the live site, privacy, or sensitive details, open a GitHub issue titled "Contact" and say it is private; the maintainer will follow up through a private channel. Say which page or screen you were on, your browser and device if the layout breaks, and the chip set preset or custom color counts if a split looks wrong.

GitHub issues

github.com/KarthikSubramanian07/ChipRatio/issues - best for reproducible bugs and concrete improvements. Use a clear title, numbered steps, what you expected, and what ChipRatio showed. Note player count, buy-in, cash vs tournament, and preset name. Screenshots help.

Optional support

Buy Me a Coffee is an optional tip jar. It does not unlock features; ChipRatio remains free.

Organization mailing context

ChipRatio is operated from Fremont, CA, United States. There is no public phone line for the project. Email and GitHub issues are the supported contact channels.

Response expectations

ChipRatio is maintained in spare time. Email and issues may wait several days. Security reports get priority. There is no paid support tier and no guaranteed response time.

Free forever. No ads. No signup.
